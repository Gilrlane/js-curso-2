## 🎲 1. Sorteador de Números

🔗 Repositório: [Sorteador de Números](https://github.com/Gilrlane/sorteador_de_numero)

### ✨ Descrição:
Aplicação simples de sorteio de números. O usuário define o intervalo e o sistema gera um número aleatório.

### 💡 Funcionalidades:
- Definição de intervalo mínimo e máximo
- Geração de número aleatório com botão de sorteio
- Feedback visual para o número sorteado

### 🚀 Tecnologias:
- HTML
- CSS
- JavaScript (Math.random)

## 🎮 2. Jogo da Adivinhação - Aula Alura

🔗 Repositório: [Jogo Aula Alura](https://github.com/Gilrlane/Jogo-aula-Alura)

### ✨ Descrição:
Jogo simples de adivinhação de número, onde o usuário tenta acertar o número secreto com dicas de "maior" ou "menor".

### 💡 Funcionalidades:
- Tentativas limitadas
- Dicas para guiar o jogador
- Resposta de acerto ou erro

### 🚀 Tecnologias:
- HTML
- CSS
- JavaScript básico (condicionais e laços)
